# 唬牌游戏正式规则 v0.7

日期：2026-05-14

## 1. 基本设定

1. 游戏支持 `3-6` 名玩家。
2. 牌组使用 `54` 张牌：标准 `52` 张扑克牌加 `2` 张大小王。
3. 大小王为通配符，在真假判定时可视为任意点数。
4. 游戏内存在固定座位顺序；玩家获胜离场后，后续轮转按原顺序跳过已离场玩家。
5. 开局洗牌并将全部牌发给玩家；不能整除时，余牌随机分配。
6. 首局首发者随机决定。

## 2. 回合开始

1. 每个回合由一名首发者开始。
2. 首发者必须先面朝下打出 `1-4` 张牌。
3. 首发者需要声明“`X 张某点数`”，例如“`3 张 4`”。
4. 本回合可声明的点数只能是 `A-K`，不能声明大小王。
5. 声明中的张数必须与实际打出的牌数一致。
6. 玩家只能对点数撒谎，不能对张数撒谎。
7. 首发者一旦声明了本回合点数，本回合后续所有出牌者都只能声明这个点数，直到本回合结束。

## 3. 上家与行动

1. `上家` 指本回合里最近一次实际出牌的玩家，不是固定座位上的前一位。
2. 从首发者之后开始，玩家按座位顺序循环行动。
3. 首发者在同一回合内可以再次获得行动机会，甚至多次获得行动机会。
4. 轮到玩家行动时，只有三个选择：
   - `质疑上家`
   - `出牌`
   - `跳过`
5. `质疑` 只能质疑当前上家最近打出的那一手牌，不能回头质疑更早的牌。
6. 玩家如果选择 `出牌`，就视为放弃对旧上家的质疑权，并立刻成为新的上家。
7. 玩家如果选择 `跳过`，则同时放弃这一次的质疑权和出牌权；上家不变。
8. 每次出牌都必须打出 `1-4` 张牌。

## 4. 质疑结算

1. 质疑时，只翻开被质疑者最近打出的那一手牌。
2. 更早压在桌面上的牌不参与本次真假判定。
3. 如果被质疑的那一手牌中，所有牌都属于本回合点数，或为大小王，则本次声明成立。
4. 声明成立时，`质疑失败`，由质疑者拿走桌面所有牌。
5. 如果被质疑的那一手牌中，存在既不是本回合点数、也不是大小王的牌，则本次声明不成立。
6. 声明不成立时，`质疑成功`，由被质疑者拿走桌面所有牌。
7. 只要发生一次质疑并完成结算，当前回合立刻结束。

## 5. 无人质疑结束回合

1. 某位玩家出牌后，他会成为当前上家。
2. 从他的下一位仍在场玩家开始继续轮转。
3. 如果在他下一次本该再次获得行动机会之前，其他所有仍在场玩家都只选择了 `跳过`，期间没有任何人 `质疑`，也没有任何人 `出新牌`，则判定该玩家 `无人质疑通过`。
4. 一旦出现 `无人质疑通过`，当前回合立刻结束。
5. 回合以 `无人质疑通过` 结束时，桌面所有牌直接清空，不归任何玩家。

## 6. 出空、待胜利与离场

1. 玩家在自己出牌后手牌变成 `0`，不会立刻获胜，而是进入 `待胜利` 状态。
2. 玩家进入 `待胜利` 状态时，必然也是当前上家。
3. 如果 `待胜利` 玩家随后被质疑且 `质疑成功`，则其待胜利状态取消，并按规则拿走桌面所有牌。
4. 如果 `待胜利` 玩家随后被质疑但 `质疑失败`，则在该次结算完成后，该玩家立即获胜并离场。
5. 如果 `待胜利` 玩家还没被质疑，就有其他玩家成功打出新的一手牌，导致上家从他变成别人，则该玩家立即获胜并离场。
6. 如果 `待胜利` 玩家一直保持为上家，并触发了 `无人质疑通过` 结束回合，则该玩家立即获胜并离场。
7. 玩家获胜后立即离场，不再参与后续回合、出牌、质疑或跳过。
8. 获胜玩家离场后，其余玩家继续游戏，而不是立即结束整局。

## 7. 下一回合首发者

1. 如果回合因 `无人质疑通过` 结束，则下一回合首发者是本次 `无人质疑通过` 的上家。
2. 如果回合因 `质疑成功` 结束，则下一回合首发者是 `质疑者`。
3. 如果回合因 `质疑失败` 结束，则下一回合首发者是 `被质疑但未被质疑成功的出牌者`。
4. 如果规则指定的下一回合首发者已经因获胜离场，则首发权顺延给他之后的下一名仍在场玩家。

## 8. 整局结束

1. 获胜顺序按玩家实际触发 `获胜并离场` 的先后顺序记录。
2. 当场上只剩 `1` 名未获胜玩家时，本局结束。
3. 如果需要完整排名，则最后剩下的那名玩家记为最后一名。

## 9. 规则实现备注

1. 服务端必须保存真实手牌和桌面牌堆，客户端默认只能看到自己手牌与公开信息。
2. 客户端公开信息至少包括：
   - 当前回合点数
   - 当前上家
   - 最近一手声明的张数
   - 轮到谁行动
   - 桌面总牌数
   - 已离场排名
3. 超时、断线重连、托管等线上行为不属于本规则文档，后续单独定义。
